# Tech Fest 2026 — RGGEC Kangra

Official web portal for **Tech Fest 2026** at Rajiv Gandhi Government Engineering College (RGGEC) Kangra. Built with **De Stijl Abstrato Neoplasticism** aesthetics and modern responsive engineering.

## 🎯 The 5 Competition Arenas
1. **[01 Challenge – Coding](coding.html)** — 3 rounds (Code Blitz, Debug the Beast, Final Build) in C/C++ & Python.
2. **[02 Typing Race](typing-race.html)** — 2-minute live race at MAT Lab with interactive WPM & accuracy simulator.
3. **[03 Web Development](web-development.html)** — Solo/Team web building with GenAI tools allowed.
4. **[04 Prompt Meme Battle](prompt-meme-battle.html)** — AI prompting comedy battle for solo/duo contenders.
5. **[05 Soldering Competition](soldering-competition.html)** — 45-minute practical electronics challenge (₹20 entry fee, coordinated by Ramneek).
