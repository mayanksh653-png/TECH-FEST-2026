Official Regulations

Rules & Guidelines

  • Individual participation: No pairs or team submissions allowed.
  • Two Supported Languages: Only C / C++ and Python are permitted.
  • Problem Statements (PS) Policy:
    • Round 1 & Round 2: Problem statements and tasks will be provided in both languages (C/C++ and Python).
    • Round 3 (Final Build): Individual choice based. Participants can choose either C/C++ or Python to write their final build.
  • Follow the given time limits: Clocks run strictly for each round.
  • AI tools are not allowed: Strictly no ChatGPT, GitHub Copilot, or automated assistants.
  • Late submissions will not be accepted: Submit before the countdown hits 00:00.
  • Coordinator's decision is final: Rules are binding for all participants.
